> 版本：v1.0 | 日期：2026-05-19 | 基于北航飞行技术专业培养方案 & AIM力学大模型架构参考

## 一、项目背景与目标

### 1.1 项目定位

**"小飞"** 是一个面向北京航空航天大学飞行技术专业学员的智能化学科学习平台。以飞行学员在校专业课程学习为核心场景，构建"AI助教 + 知识图谱 + 题库训练 + 学情追踪"四位一体的智能学习助手。

### 1.2 核心目标

| 维度 | 目标 |
|------|------|
| **知识覆盖** | 完整覆盖飞行技术专业培养方案中的核心专业课程（飞行原理、航空气象、空中导航、航空仪表、空中管制、航空法规等） |
| **智能辅导** | 基于大语言模型 + RAG知识库，提供7×24小时精准答疑、概念解释、计算题思路引导 |
| **训练体系** | 章节练习、随机组卷、闯关模式、错题本，覆盖各课程题库 |
| **学情追踪** | 学习进度可视化、知识点掌握度热力图、薄弱环节智能诊断 |
| **社区协作** | 师生问答讨论区、学习笔记分享、课程资料管理 |

### 1.3 对标参考：AIM力学大模型

AIM（AI for Mechanics）力学大模型是"101计划"中力学领域的AI赋能教育平台，其核心架构特点：

- **知识图谱驱动**：以力学知识体系为骨架，构建概念-公式-定律-习题的关联网络
- **大模型 + 领域知识库**：通用大模型结合力学专业知识库，保证回答的专业准确性
- **多模态交互**：支持公式识别、图表理解、推导过程展示
- **自适应学习路径**：基于学生模型推荐个性化学习内容

小飞智能体借鉴AIM的架构思想，面向航空飞行领域的专业课程学习场景进行适配和重构。

### 2.2 技术选型

| 层级 | 技术选型 | 说明 |

### 4.2 RAG知识库构建

**知识来源**：

| 来源 | 类型 | 处理方式 |
|------|------|---------|
| 课程课件 (PDF) | 半结构化 | PDF解析 → 文本分块 → 向量嵌入 → ChromaDB |
| 教材/讲义 | 半结构化 | 同课件处理方式 |
| 题库及解析 | 结构化 | JSON结构化存储，解析部分向量化 |
| 飞行手册/法规 | 非结构化 | 分块向量化 |

**文档处理流水线**：

```
PDF课件
  → PyMuPDF 提取文本 + 保留结构
  → 按章节/小节分块（chunk_size=512, overlap=64）
  → 为每个chunk生成元数据（课程、章节、页码、标题）
  → OpenAI Embeddings (text-embedding-3-small) 生成向量
  → 存入 ChromaDB collection
```

## 六、数据模型设计

### 6.1 核心数据库表

```sql
-- 用户表
CREATE TABLE users (
    id UUID PRIMARY KEY,
    student_id VARCHAR(20) UNIQUE,  -- 学号
    name VARCHAR(50),
    cohort VARCHAR(20),             -- 年级/期数
    created_at TIMESTAMP DEFAULT NOW()
);

-- 课程表
CREATE TABLE courses (
    id VARCHAR(20) PRIMARY KEY,     -- e.g., "081"
    name VARCHAR(100),
    en_name VARCHAR(200),
    credits INTEGER,
    semester INTEGER
);

-- 章节表
CREATE TABLE chapters (
    id VARCHAR(20) PRIMARY KEY,     -- e.g., "081-01"
    course_id VARCHAR(20) REFERENCES courses(id),
    name VARCHAR(100),
    en_name VARCHAR(200),
    order_num INTEGER
);

-- 知识点表
CREATE TABLE knowledge_points (
    id VARCHAR(20) PRIMARY KEY,
    chapter_id VARCHAR(20) REFERENCES chapters(id),
    name VARCHAR(100),
    description TEXT,
    difficulty INTEGER              -- 1-5
);

-- 题目表
CREATE TABLE questions (
    id VARCHAR(20) PRIMARY KEY,
    course_id VARCHAR(20),
    chapter_id VARCHAR(20),
    knowledge_point_ids TEXT[],     -- PostgreSQL array
    type VARCHAR(20),               -- 单选题/多选题/判断题/填空题
    difficulty INTEGER,
    title TEXT,
    options JSONB,
    correct_answer VARCHAR(10),
    explanation TEXT,
    tags TEXT[]
);

-- 用户答题记录
CREATE TABLE answer_records (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID REFERENCES users(id),
    question_id VARCHAR(20) REFERENCES questions(id),
    user_answer VARCHAR(10),
    is_correct BOOLEAN,
    time_spent INTEGER,             -- 答题用时（秒）
    created_at TIMESTAMP DEFAULT NOW()
);

-- AI对话记录
CREATE TABLE chat_sessions (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID REFERENCES users(id),
    title VARCHAR(200),
    course_id VARCHAR(20),
    created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE chat_messages (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    session_id UUID REFERENCES chat_sessions(id),
    role VARCHAR(20),               -- user / assistant
    content TEXT,
    citations JSONB,                -- 引用的知识来源
    created_at TIMESTAMP DEFAULT NOW()
);

-- 社区帖子
CREATE TABLE forum_posts (
    id SERIAL PRIMARY KEY,
    user_id UUID REFERENCES users(id),
    title VARCHAR(200),
    content TEXT,
    chapter_id VARCHAR(20),
    is_pinned BOOLEAN DEFAULT FALSE,
    view_count INTEGER DEFAULT 0,
    reply_count INTEGER DEFAULT 0,
    created_at TIMESTAMP DEFAULT NOW()
);
```

## 十、风险与应对

| 风险 | 影响 | 应对策略 |
|------|------|---------|
| LLM API成本过高 | 高 | 1) 缓存常见问题答案 2) 本地部署开源模型作为fallback 3) 设置用量配额 |
| 课件PDF解析质量差 | 中 | 多种解析方案对比（PyMuPDF/Unstructured），人工校对核心内容 |
| 题库版权/准确性 | 中 | 仅使用授权题库，建立题目审核机制 |
| 学生过度依赖AI | 中 | 计算题采用引导式回答，不直接给答案；强调自主学习 |
| 校内服务器资源有限 | 低 | 优先使用轻量方案（SQLite→PostgreSQL渐进），云端API调用 |
